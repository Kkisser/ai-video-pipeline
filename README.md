# AI-video pipeline — сборщик референсов и инструменты

Автоматизация производства коротких ИИ-роликов (TikTok/Reels/Shorts, 3D Pixar, вертикаль 9:16):
от поиска референса до готового ролика. Универсально — бренд задаётся профилем.

## Состав

- **`refcollector/`** — локальное приложение «Сборщик референсов»: веб-панель, которая
  ищет вирусные вертикалки (TikTok через Apify), кладёт в базу, даёт отбирать/скачивать/экспортировать.
  - `web.py` — панель на `127.0.0.1:8770`
  - `collect.py` — сбор из Apify (TikTok: фраза/хэштег/автор; Reels — по авторам, в работе)
  - `db.py` — база SQLite (`data/refs.db`)
  - `download.py` — скачивание отобранного (yt-dlp) в `data/downloads/<профиль>/`
  - `suggested.py` — пул авторов/хэштегов/фраз ниши
  - `cli.py` — CLI (`collect` / `list`)
- **`find_refs.py`** — бесплатный поиск по YouTube (yt-dlp), без аккаунта.
- **`apify_tiktok.py`** — быстрый тест поиска TikTok через Apify.
- **`assemble.py`** — авто-монтаж: склейка клипов + хук-текст + плашка + музыка (ffmpeg + Pillow).
- **`pipeline_flow.drawio`** — блок-схема конвейера (5 шагов) + варианты автоматизации.
- **`landing_partners.html`** — лендинг для партнёров (карта 15 этапов × 3 дорожки).
- **`ТЗ_сборщик_референсов.md`** — техзадание приложения.

## Запуск сборщика

```bash
python3 -m venv .venv && .venv/bin/pip install yt-dlp   # для скачивания
APIFY_TOKEN=ваш_токен python3 -m refcollector.web       # панель
```
Токен Apify — на apify.com (Settings → API), бесплатный тир ~$5/мес.

## Не в репозитории (gitignore)
